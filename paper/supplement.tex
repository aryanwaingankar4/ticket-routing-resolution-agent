\section{Drift detection}
% ===========================================================================
The drift evaluation measured each test's null false-alarm rate before its power (Table~\ref{tab:ieee_t13_drift_null}, Fig.~\ref{fig:drift}). The verdict is \emph{measured, not shipped}. \nb{T13.eligible_operating_points} operating points are eligible, and nothing was promoted into configuration.
\begin{itemize}
\item \emph{Conditional binomial.} Its null holds at every window (\nb{T13.conditional_binomial.null_rate_min@r3} to \nb{T13.conditional_binomial.null_rate_max@r3}).
\item \emph{Marginal binomial.} It reaches \nb{T13.marginal_binomial.null_rate_at_w200_min@r3} to \nb{T13.marginal_binomial.null_rate_at_w200_max@r3} at the largest window, so it is usable only at small windows.
\item \emph{Kolmogorov--Smirnov.} Its null rises from \nb{T13.ks.null_rate_at_w25@r3} to \nb{T13.ks.null_rate_at_w200@r3} as the window grows. It reads the p-values' discreteness, not drift, and it is never an alarm.
\end{itemize}
Table~\ref{tab:ieee_t13_realistic} gives the realistic-traffic arm, which is the drift instance of the named finding. Every power number is provisional, because its in-domain portion reuses the reference tickets.

\section{The recurring bug class, in full}
% ===========================================================================
Each of these produced a plausible result with no error. We list them because the shape, not any single fix, is the lesson.
\begin{enumerate}
\item \textbf{Stale embedding cache.} During the embedding-model swap, a cache keyed without the model name was silently reused.
\item \textbf{Private constants.} The adversarial gate script kept its own copies of the old model's thresholds.
\item \textbf{Mismatched encoder.} A batch script encoded tickets with one model against an index built by another. The dimension check that now guards every load did not exist yet.
\item \textbf{A stale ablation.} The ablation study carried its own loaders and measured the entire pre-swap pipeline. The numbers reached published results before they were caught.
\item \textbf{Wrong status enum.} The groundedness harness decided eligibility by a status value that belongs to a different gate. It would have drafted for every escalating ticket. The dry run's count disagreed with an independently measured one, and that exposed it.
\item \textbf{Incomplete grouping key.} The contamination diagnostic grouped by scenario alone. Scenario identifiers are unique only within a category, so all categories' templates merged. The result reached published results. Auditing the documents against the dataset generator's own comment caught it.
\item \textbf{A packaging rule.} A container ignore pattern did not cross directory separators, so a developer's cached embeddings were copied into the image and reused. Reading a build log caught it, and a build-time guard now enforces the rule.
\item \textbf{Hashing checkout bytes.} Provenance hashes over working-tree bytes differed across platforms because of line-ending conversion, and every source looked changed although none was. Content is now hashed with line endings normalised.
\item \textbf{A mislabelled count (found writing this paper).} The ablation table counted adversarial tickets that \emph{escalated} (\nb{T3.baseline.adversarial_escalated}) and labelled them as decided correctly. The no-gate arm beside it was counted by correctness. Correctly counted, the baseline decides \nb{T3.baseline.escalation_correct} adversarial tickets correctly, against \nb{T3.norag.escalation_correct} without the gate. The adversarial regression gate reports the former independently.
\end{enumerate}
